# I-3

## What it is

Re-signing on silence: a submission went quiet, a fresh nonce was taken and signed again, and the first one had landed
(`notes/BRIDGE-REQUIREMENTS.md` §5, "Bloque's internal incident records").

What bezent does: the exact signed bytes are stored before they are sent, and after a restart those bytes are sent again
and nothing is signed again (`REQ-EO-1`, `INV-9`). A replay returns the recorded signature. Attempt n+1 carries the same
on-chain reference and is recorded and signed only once attempt n is proven not executed at finality (`REQ-EO-6`); the
store refuses the row otherwise, and the signer's gate does the same. Residual: an attempt that is signed and never proven
stays unknown, which holds the transfer (and the refund) until it is proven or reviewed (`INV-8`).

## Pages

`key-compromise` (`../pages/key-compromise.md`) if a signature exists that bezent did not record (`REQ-IC-4`).

## Confirm

```sql
SELECT metric, asset, network, direction, value FROM ops_observables()
 WHERE metric IN ('unknown_legs', 'unknown_legs_oldest_age_seconds', 'reviews_open');
SELECT transfer_id, kind, condition, state_before_review, entered_at FROM reviews ORDER BY entered_at;
```

`intents`, `signatures` and `signed_transactions` are not readable by the operator login; the count of attempts per
transfer comes from the requester-facing status or the deployment's own notes.

## Do

- Do nothing to make a quiet submission move. The endpoint re-sends the recorded bytes by itself.
- If the transfer reaches review, resolve it only with a final coordinate (`manual_actions`, `manual_approvals` by a second
  login where value moves), as in `I-1.md`.
- If a signature turns up that no intent explains: pause (`operator_pause`) and follow `../pages/key-compromise.md`.

## Never

- No re-signing on silence, and no new nonce for a reference whose earlier attempt is not proven (`REQ-EO-6`, `INV-8`).
- No refund or failure on a timer or an unknown (`REQ-RF-1`, `REQ-RV-1`).
- No UPDATE or INSERT on intents, signatures or signed transactions (`REQ-GV-5`, `INV-9`).
